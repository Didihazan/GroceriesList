Smart Grocery List
Smart Grocery List is a web application that allows users to manage their shopping lists in a simple and intuitive way, with the ability to sync from WhatsApp groups.
Project Purpose
The main goal of the project is to simplify family grocery list management. Instead of maintaining separate lists or relying on paper reminders, the application allows all family members to add items to a shared list through the web interface or through a dedicated WhatsApp group.
Key Features

Simple Login: Login using phone number only
Intuitive Interface: Easily add, edit and delete items
Completion Marking: Mark items that have already been purchased
WhatsApp Integration: Receive items directly from a dedicated WhatsApp group
Responsive User Experience: Design adapted for mobile and desktop
Security: Protection of user details and shopping lists

Technologies
Client Side

React.js
Context API for state management
Tailwind CSS for styling
Lucide React for icons
React Router for navigation

Server Side

Node.js with Express
MongoDB with Mongoose
Full API for managing users and grocery items
